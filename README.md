# 📊 Smart Event Dashboard

A dynamic event management dashboard built using HTML, CSS, and JavaScript. This project demonstrates the use of DOM manipulation and event listeners to create an interactive user interface for managing and displaying events.

---

## Features

- Display event cards dynamically  
- Interactive UI using JavaScript  
- DOM manipulation for updating content  
- Event listeners for user interactions  
- Clean and responsive layout  

---

## Tech Stack

- HTML5  
- CSS3  
- JavaScript (DOM & Event Handling)

---

## How It Works
- The dashboard allows users to manage events through an interactive interface  
- Clicking **"Add Sample Events"** loads predefined sample events dynamically  
- Users can create a new event using the input form (title, date, category, description)  
- On clicking **"Add Event"**, the event is added instantly to the dashboard using DOM manipulation  
- Each event is displayed as a card in the "My Events" section  
- Clicking **"Clear All Events"** removes all events from the dashboard  
- Event listeners handle all button actions and update the UI in real-time without page reload
